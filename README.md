# Temas de Neotecnologías para Claude

Marketplace de plugins de Claude Code con el tema de Neotecnologías para la app de escritorio.

| Plugin | Qué es |
|---|---|
| [`neo-tema`](plugins/neo-tema) | Aurora de puntos braille en los azules de la marca sobre navy, con el isotipo en puntos. |

## Instalar

En la línea de mensajes de una sesión de Claude Code:

```
/plugin install neo-tema --marketplace NEObmonge/neo-tema
```

Desde una terminal:

```
claude plugin install neo-tema --marketplace NEObmonge/neo-tema
```
